Stremio Account Exporter vytváří soukromou JSON zálohu profilu, nainstalovaných doplňků a dostupné knihovny. Přihlašovací údaje zůstávají na tvém zařízení.

Spuštění exportu

vyžaduje lokální Node.js službu
01Spusť lokální službu

Stáhni repozitář, otevři jeho složku v terminálu a spusť lokální Node.js server.

node stremio-exporter-addon.js
02Otevři vlastní aplikaci

Po spuštění klikni na „Otevřít exportér“. Přihlašovací formulář poběží na 127.0.0.1, ne na GitHub Pages.

03Stáhni soukromou zálohu

Vyber přihlášení e-mailem a heslem nebo vlož existující AuthKey. JSON se stáhne přímo do zařízení.

Soukromý JSON soubor

Export může obsahovat historii sledování a privátní konfigurační URL doplňků. Zálohu nezveřejňuj ani necommituj do GitHubu.

Důležité: Lokální služba musí běžet na stejném zařízení. Pokud se exportér neotevře, spusť nejdříve příkaz uvedený výše. Tato webová stránka sama nečte ani neukládá tvé přihlašovací údaje.
